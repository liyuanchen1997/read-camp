# UI 设计文档（doc/01）

> 版本 v1.0 · 2026-08-16 · 亮色/暗黑双主题 · PC + 移动端响应式
> 本文件是 UI 的唯一设计基线。步骤 1 定基调，步骤 7-9 实现时细化回填，改动需同步更新本文件。

## 1. 设计语言

**关键词：精读 · 专注 · 纸感 · 静谧** —— 让用户"走进一间安静的阅览室"。

- 一切服务于"长时间阅读不疲劳"：低对比度纸感底色、衬线排版、充足留白、克制的强调色
- 交互反馈克制而明确：hover 淡金暖底、朗读句橙线跟随、气泡纸感阴影
- 管理后台与前台统一气质（Element Plus 覆主题变量），但功能优先

## 2. 设计 Token（CSS 变量，frontend/src/styles/tokens.css）

所有颜色、字体、间距、圆角、阴影以 CSS 变量定义，禁止写死。双主题：`:root`（亮色）+ `[data-theme="dark"]`（暗黑）。

### 2.3 字体

- 英文正文：`Georgia, "Noto Serif", "Times New Roman", serif`（精读气质）
- 中文正文：`"Noto Serif SC", "Songti SC", "SimSun", serif`
- UI/标签/代码：`system-ui, -apple-system, "PingFang SC", sans-serif`
- 标题：衬线同族加粗（700）

### 2.4 排版与间距

- 阅读正文：字号 1.5rem（移动端 1.25rem），行高 1.9，行宽约 72ch
- 间距阶梯：4/8/12/16/24/32/48px（--space-1..6）
- 圆角：卡片 12px、按钮/标签 8px、气泡 12px、输入框 8px
- 动效：过渡 150-250ms ease-out；气泡弹入 scale(.97→1) + fade

## 3. 页面线框与交互规范

### 3.1 全局框架（AppHeader + 内容区 + 底部安全区）

- 顶部栏：Logo（衬线"英语精读训练营"）、导航（书架/我的）、主题切换按钮（🌙/☀️）、用户菜单（头像+昵称 → 个人中心/后台管理/退出）
- 移动端：顶部栏压缩为 Logo + 主题 + 头像；**管理后台入口（导航/用户菜单/个人中心）仅桌面端（≥1024px）显示**，手机端访问 /admin 由路由守卫重定向回书架

### 3.2 登录/注册页

- 居中卡片（≤420px），纸感背景 + 极淡噪点肌理；衬线标题副文案"一间安静的线上阅览室"
- 字段：用户名/密码/昵称（可选）；错误内联提示；预置管理员首登跳转改密页（must_change_password 标记驱动）

### 3.3 书架页（Shelf）

- 网格卡片：封面区 = 无图时按标题 hash 生成暖色渐变 + 衬线标题首字母水印；下方标题/难度徽章（入门·绿 / 进阶·暖棕 / 挑战·红）/简介截断/进度角标（已读 X%）
- 筛选栏：关键词搜索 + 难度/标签过滤
- 空态：插画式简洁提示"书架空空，等待上架新文章"

### 3.4 阅读页（核心，手写定制）

- 工具栏：文章标题、进度条（细 4px 暖棕）、朗读控制（播放/暂停/停止 + 语速）、"显示翻译"开关、主题图标
- 桌面（≥1024px）：grid 双栏 1fr/1fr，左英文右中文，两独立滚动容器，中间细分割线
- 句子块：hover 淡金暖底 + 左缘 3px 色条（亮色 #B8860B / 暗色 #D4A017）；朗读当前句橙色下划线；未生成中文句显示"标注未生成"灰字占位
- 翻译开关关闭时右侧栏收起（1fr→0fr 过渡）
- **SentenceBubble 气泡**：句首锚定；①英文原句（衬线突出）②中文句子讲解 ③中文意思 ④成分标签行（**成分类型 + 对应原文片段**，如"主语 · The lion"，hover 见作用说明）⑤单词列表（word+pos+meaning）⑥操作栏：收藏（心形，点亮态绿）+ 整句朗读
- **单词解释浮层（WordBubble）**：句子气泡内单词项 **hover 即冒泡**（不另开弹窗）：word / pos / meaning / role + 发音按钮 + 加入生词本（已加入态可移除，带出处句）；180ms 延迟关闭允许移入浮层操作
- 阅读页不加载 Element Plus

### 3.5 我的（Profile）/ 生词本 / 例句收藏 / 近期阅读

- 个人中心：头像（可上传 URL）+ 昵称编辑 + 统计卡（精读文章数/进行中/平均进度）
- 生词本：分页列表，word + 词性 + 出处句 + 删除
- 例句收藏：分页列表，例句原文 + 文章标题 + 取消收藏
- 近期阅读：横向卡片列表，封面 + 标题 + 细进度条 + 上次阅读时间（相对时间）

### 3.6 管理后台（Element Plus 覆主题）

- 布局：左侧栏（文章管理/仪表盘）+ 内容区；深色模式用 EP `dark` class + 变量覆盖
- 文章列表：状态筛选（全部/上架/下架）、生成进度汇总列、上/下架开关、编辑/删除
- 文章编辑器：标题/难度/标签/摘要 + 正文 textarea（段落用空行分隔）；保存时提示切分结果（"共切分 N 句"）
- **生成对话框**：四态计数（未生成/生成中/已生成/失败）、进度条（2s 轮询）、预估 token 成本提示、取消按钮、失败句红色标记 + 单句重试按钮
- 仪表盘：用户数/文章数/上架数/生成状态统计卡

## 4. 响应式规则

| 断点 | 行为 |
|---|---|
| ≥1024px | 阅读页双栏对照；书架 3-4 列 |
| 768–1023px | 书架 2 列；阅读页仍可双栏或 Tab（自动判断） |
| <768px | 书架 1-2 列；阅读页 Tab 模式（英文/中文切换）+ 可选上下对照；工具栏紧凑条 |

移动端细节：tap=click 开气泡；气泡底部留白防遮挡；底部工具栏悬浮条 + env(safe-area-inset-bottom)。

## 5. 空态/加载态/错误态规范

- 空态：简洁图标 + 一句话提示 + 可选行动按钮
- 加载：内容骨架屏（卡片灰块 shimmer，暗色适配）；首次进入阅读页骨架 + content-visibility:auto 分片渲染
- 错误：toast 内联提示；接口 401 统一跳登录（带原路径回跳）；管理端失败句红色标记 + gen_error 悬停展示

## 6. 主题切换机制

- `[data-theme="light"|"dark"]` 挂 html 根节点；切换即时生效不刷新
- 默认跟随系统 `prefers-color-scheme`；手动选择后 localStorage 持久化（key: `readcamp-theme`），清除即回跟随
- 所有页面（含阅读区气泡、管理后台）必须走变量；新增组件前先查本文件是否有对应 token
